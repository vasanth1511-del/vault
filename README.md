# StudyVault

A student resource library for notes, question papers, and study tips. Browse, search, filter, upvote, and bookmark resources organised by department, semester, and subject.

Built with HTML, CSS, and vanilla JavaScript. Data is saved in the browser using localStorage, so no backend is needed.

## Run locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Deploy
Import this repository into Vercel as a static site (no build settings needed).
